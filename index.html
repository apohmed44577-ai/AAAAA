⚠️ تنبيه — INC مع Rising Edge

أمر INC لازم يكون شرطه عبر P (اتصال Positive Edge) — وإلا سيزيد القيمة في كل دورة مسح (Scan Cycle) طالما الزر مضغوط.

// ✅ صح — يزوّد مرة واحدة فقط لكل ضغطة ──┤ Start (P) ├── INC(MB0) // ❌ غلط — يزوّد في كل Scan Cycle طالما الزر مضغوط ──┤ Start ├── INC(MB0)
تطبيقات عملية
A
جراج 10 عربيات: INC عند الدخول — DEC عند الخروج — LIMIT (0,10) — لو MB0 ≥ 10 يغلق البوابة
B
سيراميك: ADD تراكمي لكل حجم مختلف في نفس الميمورى
C
تحويل Hz إلى RPM: RPM = (Hz × 120) / Poles
D
سكينة القطع: MOD لتحديد نوع المنتج — ثم INC للعداد المناسب
BCD و 7-Segment
  • أمر I_BCD — يحوّل Integer إلى BCD لربطه بشاشة 7-Segment
  • النطاق الصالح للتحويل: من 0 إلى 9999
  • يجب الكتابة في الـ Least Byte عشان يظهر صح
  • ربط الشاشة بالـ PLC عبر RS485 كـ Serial communication

من المرجع

الـ TONR هو التايمر الوحيد في الـ S7-1200 الذي يحتفظ بالوقت المتراكم بعد انقطاع إشارة الإدخال. يحتاج إلى Reset صريح (R=1) لإعادة الضبط. مثالي لعدّ ساعات تشغيل الماكينة وتحديد مواعيد الصيانة الدورية.

من المرجع

إشارة 4–20mA هي الأكثر استخداماً في الصناعة. الحد الأدنى 4mA (وليس صفر) يتيح اكتشاف انقطاع السلك تلقائياً — لو القيمة نزلت تحت 5530 فهذا يشير لعطل في الحساس أو انقطاع في السلك.

industrialmonitordirect.com — S7-1200 4-20mA Analog Input Tutorial
خطوتا التحويل — NORM_X ثم SCALE_X
1
NORM_X — يحوّل القيمة الخام (0 → 27648) إلى عدد عشري بين 0.0 و1.0 ويُخزَّن في متغير REAL
2
SCALE_X — يضرب ناتج NORM_X في النطاق الهندسي المطلوب (مثلاً 0–5 بار أو 0–1000 درجة)
// مثال: حساس ضغط 0–5 بار → IW100 // Step 1: NORM_X NORM_X: MIN = 0 // أقل قيمة خام MAX = 27648 // أعلى قيمة خام (10V) VALUE = IW100 // القيمة الواردة من الحساس OUT → MD20 // نتيجة عشرية 0.0..1.0 (REAL) // Step 2: SCALE_X SCALE_X: MIN = 0.0 // أقل قيمة هندسية (0 بار) MAX = 5.0 // أعلى قيمة هندسية (5 بار) VALUE = MD20 // ناتج NORM_X OUT → MD30 // الضغط الحقيقي بالبار (REAL) // ثم COMPARE للتحكم في الطرمبات CMP: MD30 >= 3.5 → Q0.0 // تشغيل الطرمبة
من المرجع

الـ NORM_X يأخذ نطاق الأعداد الصحيحة ويحوّله إلى قيمة REAL بين 0 و1. بعدها الـ SCALE_X يحوّل هذه القيمة إلى الوحدات الهندسية المطلوبة. هذه العملية ضرورية لأن أي حساب رياضي على قيم Analog يحتاج نوع REAL لتجنب فقدان الكسور العشرية.

LEC 08 Inverter (VFD) — الفرن الصناعي — Shift Register ▼
ربط الإنفرتر (VFD) بالـ PLC

الإنفرتر يتحكم في سرعة الموتور بتغيير التردد (Hz). الـ PLC يرسله التردد المطلوب عبر إشارة Analog Output (0–10V أو 4–20mA).

// المعادلة الكاملة: Hz مطلوب → QW80 (VFD) Step 1: احفظ التردد المطلوب في MD50 (REAL) مثال: MD50 = 35.0 // 35 Hz Step 2: NORM_X MIN = 0.0 MAX = 50.0 // Max Speed = 50 Hz VALUE = MD50 OUT → MD60 // = 0.70 (70% من القصوى) Step 3: SCALE_X MIN = 0 MAX = 27648 VALUE = MD60 OUT → QW80 // يُرسَل للـ Analog Output
تاسك — الفرن الصناعي (0 → 1000°C)

فرن فيه 3 هيترات ومروحة دفع هواء — تحكّم بتتابع محدد عند مستويات حرارة معينة.

1
بعد Start: الثلاث سخانات (H1, H2, H3) تشتغل + لمبة Alarm تضيء
2
عند 760°C: H1 يفصل + لمبة Alarm ترمش (Flashing) + مروحة تشتغل
3
بعد دقيقة واحدة (T#60S): تايمر TON → H2 يفصل
4
بعد 5 دقائق (T#5M) من فصل H2: تايمر TON آخر → H3 يفصل
5
لما الحرارة تنزل لـ 600°C: الثلاث سخانات تشتغل مجدداً + مروحة لمدة 3 دقائق
6
الدورة تتكرر تلقائياً (Control Loop)
// قراءة الحرارة وتحويلها NORM_X(IW100, 0, 27648) → MD20 SCALE_X(MD20, 0.0, 1000.0) → MD30 // درجة الحرارة الحقيقية // فصل H1 عند 760°C CMP: MD30 >= 760.0 → RESET(Q0.0) → TON(T#60S) → RESET(Q0.1) // إعادة التشغيل عند 600°C CMP: MD30 <= 600.0 → SET(Q0.0, Q0.1, Q0.2) → TON(T#3M, Fan_Timer)
Shift Register — المرة الجاية

الـ Shift Register يخزّن سلسلة من الـ Bits ويحركها بمقدار خطوة واحدة في كل Scan Cycle أو Trigger. يُستخدم في:

  • تتبع منتجات على سير ناقل (كل منتج في خانة منفصلة)
  • تسلسل محطات الإنتاج
  • تأخير إشارات بعدد محدد من الخطوات
